# EasyDoPhoto

광고 · 인터넷 권한 없는 안드로이드 카메라 · 사진 편집 앱. 앱을 켜면 바로 카메라가 나오고, 앨범과 편집으로 이어짐. 사진은 기기 밖으로 나가지 않음.

## 기능

| 영역 | 내용 |
|---|---|
| 카메라 | 전면 · 후면, 플래시, 타이머, 비율(3:4 · 9:16 · 1:1), 격자, 확대, 눌러서 초점, 밝기, 볼륨 버튼 촬영 |
| 프리셋 | 인물 · 음식 · 풍경 등 16종을 미리보기에 바로 적용. 언제 쓰는지 설명이 붙어 있어 찍는 대상만 고르면 됨 |
| 상세 옵션 | 장소(야외 · 실내 · 어두운 곳), 분위기, 사람 프리셋은 구도(전신 · 상반신 · 얼굴)와 안내선 |
| 내 프리셋 | 색 · 화각 · 각도 · 렌즈 효과를 직접 조절해 저장. 편집 필터에서도 사용 |
| 앨범 | 전체 사진 날짜별 격자, 폴더별 보기, 여러 장 선택 · 공유 · 삭제, 사진 확대, 정보 보기 |
| 회전 · 자르기 | 좌우 · 상하 반전, 90도 회전, 0.1도 단위 회전, 상하 · 좌우 기울기, 기울임, 자유 · 고정 비율 자르기, 크기 조정 |
| 보정 · 필터 | 노출 · 대비 · 하이라이트 · 그림자 · 화이트 밸런스 · 채도 · 선명도 · 비네트 · 그레인 등, 필터 강도 조절 |
| 그리기 | 펜 · 마커 · 붓 · 모자이크 · 직선 · 화살표 · 사각형 · 타원 · 글자 · 채우기 · 스포이트 |
| 지우기 | 투명하게 지우는 지우개, 되살리기, 비슷한 색 지우기, 올가미 |
| 저장 | PNG · JPEG · WEBP, 설정과 내 프리셋 백업 · 복원 |

## 설치

[Releases](../../releases)에서 `EasyDoPhoto-<버전>.apk`를 받아 설치. Android 11 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 설정 · 프리셋 유지
- 앱 안 업데이트 알림 없음. 설정 → 배포 페이지에서 직접 확인
- 서명 인증서 SHA-256: `acb218cf6b835dffa90e847c8b74dd71faaeeecfdbe0d130cdbe460dc1c4ed82`
  (`apksigner verify --print-certs EasyDoPhoto-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 저장하는 사진에 EXIF · 위치 정보를 넣지 않음
- 카메라 권한은 촬영에, 사진 권한은 앨범에 전체 사진을 보여 주는 데만 사용. 사진 권한을 거부하면 앱이 저장한 사진만 보임
- 사진 삭제는 항상 시스템 확인 창을 거침

## 알려진 점

- Galaxy S24+에서만 시험함
- 필터를 켠 미리보기는 저장되는 사진과 색이 조금 다를 수 있음. 해상도도 낮아질 수 있으나 저장 사진에는 영향 없음
- 프리셋 값은 시작값으로, 실제 사진으로 충분히 다듬지 않음
- 필터는 저장 결과에 그대로 적용되며 원본을 따로 남기지 않음
- 2400만 화소가 넘는 사진은 편집할 때 줄여서 열림
